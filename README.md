# Web Undangan Pernikahan Digital

Dibuat dengan React + Vite + Tailwind CSS dan Firebase Firestore untuk RSVP serta buku tamu.

## Struktur Proyek

```bash
.
├── src/
│   ├── components/
│   ├── App.jsx
│   ├── data.js
│   ├── firebase.js
│   ├── index.css
│   └── main.jsx
├── .firebaserc
├── firebase.json
├── firestore.rules
├── index.html
├── package.json
├── postcss.config.js
├── tailwind.config.js
├── vite.config.js
└── README.md
```
